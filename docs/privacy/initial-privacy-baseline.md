# Initial privacy baseline

This Phase 0 deployment contains no real alumni information.

Before accepting private member data:

1. Publish plain-language privacy and consent notices.
2. Enable and test Row Level Security on every exposed table.
3. Keep uploaded media private by default.
4. Verify presentation seed data has been removed.
5. Record administrative and publication changes in an audit trail.
6. Provide correction, consent-withdrawal, and deletion procedures.

Never commit names, contact details, credentials, exports, photographs, or database backups to this repository.
